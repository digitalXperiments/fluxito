Access model

User roles

Owner, Admin, and Member are the built-in project roles. Use custom roles above for fine-grained tool and provider access, then assign them to members from the Users tab.

OW Owner

Full control

Owns the project boundary and can transfer ownership or delete the project.

  • Manage every member and role
  • Connect platforms and notification senders
  • Transfer ownership and delete the project
AD Admin

Operational control

Runs the workspace day to day without ownership-level destructive actions.

  • Invite and remove non-owner members
  • Connect data platforms and manage senders
  • Cannot transfer ownership or delete the project
MB Member

Project access

Can use the project workspace without changing access, credentials, or billing boundaries.

  • View and use project resources
  • Run allowed workflows in the active project
  • No member, connection, or notification admin
