UX Flow Comparison: Current vs Proposed

Summary of the identified pain points in the existing flow and how the new onboarding journey and home redesign solve them.

Current Flow (Problematic)

Confusing First Impressions

  • Silent project creation: User is automatically assigned a generic {Name}'s Project without ever being asked for workspace name, currency, or timezone.
  • Tutorial disconnect: If redirected to /tutorial, Step 4 shows cards for Claude/ChatGPT but provides zero input for API keys or clear guidance on subscriptions.
  • Dumped on Home without AI setup: User lands on /home with a prominent static chat composer, but asks fail because no AI provider key has been configured.
  • Buried Settings: User has to discover Settings → AI Providers on their own to add a key.
  • MCP is hidden: MCP availability is an 11px tiny footnote at the bottom of the right rail, despite being Fluxito's primary value proposition!
  • Rigid viewport: The chat bar is fixed at the bottom, restricting the viewport and pushing the feed into a cramped sub-window.
Proposed New Flow (This Prototype)

Guided, Intentional & MCP-First

  • Explicit Onboarding Journey: Signup directly lands on a guided 3-step setup journey before reaching the home page.
  • Clear AI Engine Choice: User explicitly chooses whether to use MCP with their Claude/Cursor/ChatGPT subscription (zero token cost) or add an in-app API key.
  • Intentional Project Creation: User creates and customizes their workspace (Name, slug, currency, timezone, focus areas) before entering.
  • Conditional Landing: Only after completing (or intentionally skipping) the onboarding journey does the user enter /home.
  • MCP is the Star Feature on Home: Prominent spotlight card right under the morning briefing with 1-click copy for Claude Desktop, Cursor, ChatGPT, and Windsurf.
  • Floating, Non-Blocking Chatbar: Chat bar is moved out of the static viewport flow into a floating, dockable command pill with ⌘K shortcut.

Backend Routing Implementation Plan:

  1. Modify app/api/auth_routes.py and app/api/google_oauth_routes.py: If user has not completed onboarding or has no intentional project, redirect to /onboard (the new 3-step wizard).
  2. Do not silently auto-create default projects on signup; let Step 2 of /onboard call POST /api/projects.
  3. Update app/templates/dashboard_home.html and app/static/css/home.css to introduce the MCP Hero spotlight and the floating chat bar container.
